# Матрица: версия matrix-22-v2

Матрица — отдельный символический продукт по календарной дате рождения. Она не меняет
основную концепцию ежедневных раскладов по дате и месту рождения. Числа не зависят от
имени, пола, города, случайности или ответа языковой модели. Тексты — оригинальные
редакционные трактовки с практиками для самоанализа. Ни результат, ни «ресурсные уровни»
не являются медицинской или психологической диагностикой.

## Источники и выбранная конвенция

Проверено 8–9 сентября 2026 года:

* [Пошаговый расчёт калькулятора LadiniMatrix](https://ladinimatrix.ru/calculate-matrix-yourself/):
  основной крест, родовой квадрат, два дополнительных центра, линии и итоговые направления.
  Независимый контрольный пример 31.10.1984 закреплён в тесте.
* [Описание арканов этого же проекта](https://ladinimatrix.ru/2024/06/20/lichnoe-prednaznachenie-v-matrice-sudby/):
  используем нумерацию 8 — Справедливость, 11 — Сила. Другие колоды могут менять их местами.
  13 назван «Трансформация», 22 — «Шут»; это названия символов, не прогноз событий.
* [Схема, опубликованная LadiniMatrix](https://ladinimatrix.ru/wp-content/uploads/2024/06/kak-rabotat-s-matricej-sudby.png):
  ориентир для структуры вложенных осевых и родовых точек. Иллюстрация и тексты не копировались
  в продукт. Графика построена кодом с собственной палитрой и вёрсткой.
* [Методика калькулятора Кодаркан](https://kodarkan.ru/metodika/) и
  [его денежный канал](https://kodarkan.ru/matrica/dengi/): второй числовой пример 14.03.1991,
  формулы входов и общей точки; авторы прямо отмечают различия школ.
* [Гид калькулятора FateLyra](https://fatelyra.com/ru/blog/how-to-read-destiny-matrix-chart):
  последовательное сложение соседей для трёх внутренних узлов нижнего правого сектора.
* [Взрослая схема NumSoul](https://numsoul.com/ru/calculators/adult): возрастные ориентиры
  0–75 лет через пять лет; таблица семи символических уровней.

Это публичные описания самих калькуляторов, а не подтверждение научной достоверности.
Не заявляем сертификацию, аффилиацию с какой-либо школой или единственную каноническую
полноту. Полнота продукта означает объяснение **всех значений именно нашей схемы**:
30 кругов, 10 итогов, 7 строк по 3 значения. Выбранная конвенция зафиксирована кодом
и контрольными примерами; другие школы могут показывать дополнительные слои и иные названия.

## Единственный источник расчёта

`matrix_model.calc_matrix()` возвращает числа, названия, адреса, координаты, формулы,
линии и таблицы. `matrix_image` рисует этот объект; `matrix_report` объясняет его же.
Не добавлять независимые формулы в обработчики или в промпт модели.

Пусть `r(n)` оставляет положительные целые `1..22`, а при `n > 22` складывает цифры,
повторяя действие при необходимости. `r(22)=22`, `r(29)=11`, `r(31)=4`.
Не использовать остаток от деления на 22, вычитание 22 или цифровой корень до 9.

| Адрес | Расчёт | Положение |
|---|---|---|
| A | r(день) | слева, возраст 0/80 |
| B | месяц | сверху, 20 |
| C | r(сумма цифр года) | справа, 40 |
| D | r(A+B+C) | снизу, 60 |
| E | r(A+B+C+D) | центр |
| F | r(A+B) | верхний левый, 10 |
| G | r(B+C) | верхний правый, 30 |
| H | r(C+D) | нижний правый, 50 |
| K | r(D+A) | нижний левый, 70 |

Для каждого `X` из `A,B,C,D,F,G,H,K`: `X1 = r(X+E)` — внутренняя точка,
`X2 = r(X+X1)` — точка ближе к внешней вершине. Дополнительно:
`A3 = r(A1+E)`, `B3 = r(B1+E)` — внутренние зелёные точки.

Общая точка `Q = r(C1+D1)`; партнёрская `L = r(D1+Q)`; денежная `M = r(C1+Q)`.
Отношения идут `D1 → L → Q`, деньги `Q → M → C1`. Оба канала лежат на прямой
`x+y=0.65` нижнего правого сектора; Q находится на диагонали отцовской ветви.
Последовательность опыта («кармический хвост») — `D1 → D2 → D`.
Эти названия — продуктовая интерпретация позиции; прошлые жизни и поступки родственников
по числам не устанавливаются.

Отцовская диагональ `F → F2 → F1 → E → H1 → H2 → H`.
Материнская диагональ `G → G2 → G1 → E → K1 → K2 → K`.
Исправлена старая ошибка, когда родовые линии проходили по рёбрам внешнего рисунка.
Внешние H/K не называются деньгами/любовью. Старые FG/GH/HK/KF возвращаются только
для совместимости: это суммы углов, не нарисованные безымянные точки.

Дополнительные итоги:

* `sky=r(B+D)`, `earth=r(A+C)`, `personal=r(sky+earth)`;
* `father=r(F+H)`, `mother=r(G+K)`, `social=r(father+mother)`;
* `spiritual=r(personal+social)`, `planetary=r(social+spiritual)`;
* `family_center=r(F+G+H+K)`, `total_center=r(E+family_center)`.

Ресурсная таблица использует пары `A/B`, `A2/B2`, `A1/B1`, `A3/B3`, `E/E`, `C1/D1`,
`C/D`. Первые два столбца показывают соответствующие числа, третий — `r(левое+правое)`.
Традиционные имена семи чакр приведены в разборе, а на изображении даны понятные
названия сфер. «Действие» и «Восприятие» заменяют медицински звучащие названия столбцов.

Возраст идёт по часовой стрелке от A: `0,10,20,30,40,50,60,70,80=A`.
Отдельное внешнее кольцо содержит видимые годовые штрихи и подписи пятилетий.
Энергии отдельных лет не рассчитываются и не выдаются за скрытый прогноз.
Возраст 80 обозначает замыкание схемы, а не продолжительность жизни.

## API и доставка

```python
from matrix_image import calc_matrix, build_matrix_image
from matrix_report import build_matrix_report, build_matrix_report_html

model = calc_matrix("1984-10-31")
png_path = build_matrix_image(user)       # уникальный временный PNG 1400 × 2320
chunks = build_matrix_report(user)        # list[str], Telegram HTML, <3900 символов
html_path = build_matrix_report_html(user) # автономный HTML с встроенным PNG
```

Изображение и HTML возвращают новый файл при каждом вызове, поэтому параллельные
запросы одного пользователя не перетирают файл друг друга. Обработчик удаляет временные
файлы в `finally` после отправки. Ошибки даты или отсутствующего кириллического шрифта
поднимаются исключением: не списывать оплату за неготовый/недоставленный результат.
CPU-работу отправлять через `asyncio.to_thread`. Бот может показать «Собираю разбор
матрицы…» во время реального построения, без фиктивных процентов и искусственной задержки.

HTML открывается офлайн, имеет оглавление, мобильную вёрстку, печать/сохранение в PDF
через браузер и приложение с формулами каждого круга. Для резкости желательно отправлять
оригинальный PNG также документом либо дать его в скачиваемом HTML: Telegram сжимает фото.

Требования: Pillow и кириллический TrueType-шрифт. Debian/Ubuntu: `fonts-dejavu-core`.
Windows: системный Arial. Можно задать `MATRIX_FONT_REGULAR`/`MATRIX_FONT_BOLD`.
Секреты и сетевые вызовы для расчёта и разбора не нужны.
